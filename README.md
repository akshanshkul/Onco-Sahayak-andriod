# Onco Sahayak — React Native + TypeScript + NativeWind

Frontend-only cancer-care support UI prototype.

- React Native + Expo
- TypeScript (`.ts` / `.tsx`)
- NativeWind / Tailwind CSS
- React Navigation
- Expo Document Picker
- Local mock data only

## Run

```bash
npm install
npx expo start
```

No backend is included. Hospital/NGO data and AI responses are mocked locally.
